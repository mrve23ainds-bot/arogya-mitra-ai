#  MediSphere – AI Health Assistant

MediSphere is an AI-powered multilingual healthcare assistant that helps users check symptoms, locate nearby healthcare facilities, and access emergency medical information through an easy-to-use interface.

##  Features

- AI-powered symptom checker
- Multilingual support
- Nearby hospitals and clinics
- Medical store locator
- Emergency contacts
- User-friendly interface

## Tech Stack

- React.js
- TypeScript
- Vite
- Tailwind CSS
- Supabase

## ▶️ Getting Started

```bash
git clone https://github.com/mrve23ainds-bot/AI-HEALTH-ASSISTANT.git
cd AI-HEALTH-ASSISTANT
npm install
npm run dev
```
